# Gazebo + ROS 2

The ROS 2 nodes of the cell. They are started by `ros2 launch scara_description gazebo.launch.py`
(and `mujoco_ros.launch.py`, which uses the same nodes with MuJoCo); the ones marked *you* are for you to run.

| program | what it does |
|---|---|
| `scara_color_sorter.py` | sorting / command / sequence logic (node) |
| `scara_vision_node.py` | finds the pucks in the fixed camera (node; no windows when there is no screen) |
| `scara_puck_spawner.py` | puts pucks on the belt and clears the bins (node) |
| `scara_pose_relay.py` | names the puck poses coming from Gazebo (node) |
| `scara_rviz_scene.py` | the cell in RViz (node) |
| `scara_ask.py` | *you*: type or say colours (`--voice`) |
| `pick_and_place.py` | *you*: `red 2` – two red pucks, wait until done |
| `scara_teleop.py`, `scara_joystick.py` | *you*: keyboard / Xbox pad (`mode:=manual`) |
| `scara_doctor.py` | *you*: what is wrong with my running cell? |
| `worlds/` | the three Gazebo worlds (sorting, command, table), generated by `tools/build_scene.py` |

```bash
ros2 launch scara_description gazebo.launch.py mode:=command
python3 gazebo/scara_ask.py
```
